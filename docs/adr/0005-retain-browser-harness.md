# Retain Browser Harness as the browser transport

Build upon jev-ultrafast's indexed DOM observations, Jev action selection, and guarded execution while retaining Browser Harness, as explicitly selected by the user over Playwright. Reliable session-scoped evidence capture and isolated browser execution must therefore be implemented over the harness rather than substituting another automation framework. Reused upstream code retains its MIT attribution; the existing browser-harness workspace remains unchanged.
