# Triage labels

| Role | GitHub label | Meaning |
| --- | --- | --- |
| Needs triage | `needs-triage` | Maintainer must evaluate the request |
| Needs information | `needs-info` | Required information is missing |
| Ready for an agent | `ready-for-agent` | Fully specified; check blockers before starting |
| Ready for a human | `ready-for-human` | Human implementation or action is required |
| Not planned | `wontfix` | Will not be implemented |
